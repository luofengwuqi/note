# 使用HotPE装双系统

装双系统就是：用 HotPE 制作启动 U 盘进入 PE，把一个系统的镜像装到另一块分区里。完整步骤如下：
一、制作 HotPE 启动盘
1. 去官网 https://www.hotpe.top/download/ 下载 HotPE，解压后右键以管理员身份运行 HotPE Client.exe
2. 首页点「开始下载」等待环境包下载完成
3. 点「安装到 U 盘」，选好 U 盘后点「开始安装」（会格式化 U 盘，注意备份数据）
二、准备镜像与分区
4. 把第二个系统的 ISO 镜像（官方/原版，如 Windows 10/11）复制进 U 盘
5. 开机按启动快捷键（F12/F8/ESC 等）选 U 盘进入 HotPE
三、分区
6. 打开桌面上的 DiskGenius / 分区助手，在现有系统所在盘上压缩出空闲空间（比如从 C 盘分 60~100GB 出来建一个新分区），不要动原系统分区
四、安装第二个系统（二选一）
- 用内置 HotSysSetup（官方推荐）：选镜像文件 → 选安装分区（就是你新建的空分区，一定别选错）→ 开始安装 → 重启继续
- 或用 Windows 安装器（winsetup）等工具：选择 ISO、引导分区（EFI 就选 ESP 分区，MBR 就选目标盘）、安装分区，按提示完成
五、完成
安装后会生成多系统引导菜单，开机即可在两个系统间选择。装完系统建议用「引导修复工具」刷新一下启动项。
关键提醒：
- 安装时选择「自定义/从镜像文件安装」，不要选错分区（装第二个系统会格式化所选分区）
- 中文/原版系统一般不自动识别第二系统，若装完后菜单缺失，进 PE 用「引导修复工具」（如 NTBootFix）修复即可

- PC（Personal Computer）= 个人电脑，就是你正在用的这台电脑。
- PE（WinPE / Preinstall Environment）= 预安装环境，一个"迷你系统"，不装在硬盘上，从 U 盘或光盘启动。专门用来装系统、修复系统、给硬盘分区、救数据（比如系统蓝屏打不开时用它）。
