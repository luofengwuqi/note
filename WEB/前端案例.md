# 常见bug
## 浮点数溢出问题
安装:npm install decimal.js --save  
导入:import Decimal from 'decimal.js';
使用:
```javascript
  // 1. 实例化（支持数字、字符串入参，推荐用字符串避免原生精度问题）
const num1 = new Decimal(0.1); // 不推荐：0.1 本身已有精度误差
const num2 = new Decimal('0.1'); // 推荐：字符串入参，完全精准

const num3 = new Decimal(100); // 整数可直接传数字

// 2. 实例的本质：不是普通数字，是包含高精度数值的对象
console.log(num2); // Decimal { s: 1, e: -1, c: [1] }（内部存储结构）
console.log(typeof num2); // "object"

// 3. 精度配置
// 全局配置：保留 2 位小数，四舍五入
Decimal.set({ precision: 2, rounding: Decimal.ROUND_HALF_UP });
```
| 方法         | 作用         | 语法               |
| ------------ | ------------ | ------------------ |
| `add()`      | 加法         | `a.add(b)`         |
| `mul()`      | 乘法         | `a.mul(b)`         |
| `sub()`      | 减法         | `a.sub(b)`         |
| `div()`      | 除法         | `a.div(b)`         |
| `toNumber()` | 转普通数字   | `dec.toNumber()`   |
| `toFixed(n)` | 格式化小数   | `dec.toFixed(2)`   |
| `equals()`   | 比较是否相等 | `a.equals(b)`      |

# 防止溢出
## 文字溢出省略
![](./assets/26-2-16.png)
以下答案来自chatgpt 
```css
/* 单行文本 */
<style>
.text-container {
  width: 200px; /* 容器的宽度 */
  white-space: nowrap; /* 防止换行 */
  overflow: hidden; /* 隐藏超出部分 */
  text-overflow: ellipsis; /* 显示省略号 */
}
</style>

/* 多行文本 */
.text-container {
  display: -webkit-box;
  -webkit-line-clamp: 3; /* 显示 3 行文本 */
  -webkit-box-orient: vertical;
  overflow: hidden;
  text-overflow: ellipsis;
  height: 60px; /* 设置高度，限制显示行数 */
}
```
-webkit-line-clamp 依然是实现多行文本截断并显示省略号的主流方法  
新版本的浏览器仍然可以支持这个属性，但它是 Webkit 引擎特有的  
为了保证兼容性，可以加上 -webkit 前缀。  
## 长单词强制折行
(避免撑破容器)
```css
    word-break: break-all;    // 强制所有字符内折行（中英文都生效）
    overflow-wrap: break-word;// 针对长单词/URL 的折行（word-wrap 的新标准）
    white-space: normal;      // 恢复默认换行规则，配合折行属性生效
```

## 添加滚动条
在会溢出的父容器添加
```css
overflow-y: auto;
```
更美观:
```css
/* 在 Webkit 浏览器中自定义滚动条 */
.experience-container::-webkit-scrollbar {
  width: 8px; /* 设置滚动条的宽度为 8px */
}

/* 自定义滚动条滑块（可以拖动的部分） */
.experience-container::-webkit-scrollbar-thumb {
  background: #888; /* 设置滑块的背景颜色为灰色 (#888) */
  border-radius: 4px; /* 设置滑块的圆角半径为 4px，使滑块的角变圆润 */
}

/* 当鼠标悬停在滚动条滑块上时，改变滑块的背景颜色 */
.experience-container::-webkit-scrollbar-thumb:hover {
  background: #555; /* 设置滑块在鼠标悬停时的背景颜色为深灰色 (#555) */
}

```


## 全局样式重置(Vue)
1. 在 Vue 项目的 src/assets/css/ 目录下新建 reset.css(代码放在下面)
2. 在项目入口全局引入重置文件
* 方式 1：在 main.js 中直接导入（推荐）
```javascript
import Vue from 'vue'
import App from './App.vue'
// 全局引入重置样式（关键：会作用于所有页面）
import './assets/css/reset.css'
```
* 方式 2：在 App.vue 的 style 中导入（不加 scoped）
```vue
  <style>
  /* 不加 scoped，样式全局生效 */
    @import './assets/css/reset.css';
  </style>
```
* 方式 3：在 vue.config.js 中配置（适合大型项目）
```javascript
// vue.config.js
const { defineConfig } = require('@vue/cli-service')
module.exports = defineConfig({
  css: {
    loaderOptions: {
      css: {
        // 全局引入 reset.css
        additionalData: `@import "@/assets/css/reset.css";`
      }
    }
  }
})
```
下面是完整的css代码 复制粘贴就行
```css
  /* src/assets/css/reset.css */
/* 1. 重置所有元素的内外边距、盒模型 */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box; /* 让宽高包含内边距和边框，更易布局 */
}

/* 2. 重置body的默认样式 */
body {
  font-family: "Microsoft Yahei", "Helvetica Neue", Helvetica, Arial, sans-serif; /* 统一字体 */
  color: #333; /* 统一文本颜色 */
  background-color: #fff; /* 统一背景色 */
  line-height: 1.5; /* 统一行高 */
}

/* 3. 重置列表默认样式（ul/ol） */
ul, ol {
  list-style: none; /* 去掉列表符号 */
}

/* 4. 重置a标签默认样式 */
a {
  text-decoration: none; /* 去掉下划线 */
  color: inherit; /* 继承父元素颜色，不再默认蓝色 */
  cursor: pointer; /* 鼠标悬浮变手型 */
}
a:hover, a:active, a:focus {
  text-decoration: none; /* 去掉 hover 下划线 */
  outline: none; /* 去掉聚焦外边框 */
}

/* 5. 重置图片默认样式 */
img {
  display: block; /* 去掉图片底部默认间隙 */
  max-width: 100%; /* 自适应宽度 */
  border: none; /* 去掉默认边框 */
}

/* 6. 重置表单元素默认样式 */
input, textarea, select, button {
  font-family: inherit; /* 继承全局字体 */
  font-size: inherit; /* 继承全局字号 */
  color: inherit; /* 继承全局颜色 */
  outline: none; /* 去掉聚焦外边框 */
  border: none; /* 去掉默认边框 */
  background: none; /* 去掉默认背景 */
}
button {
  cursor: pointer; /* 按钮手型 */
}

/* 7. 重置表格默认样式 */
table {
  border-collapse: collapse; /* 合并单元格边框 */
  border-spacing: 0; /* 去掉单元格间距 */
}

/* 8. 重置标题标签（h1-h6）默认样式 */
h1, h2, h3, h4, h5, h6 {
  font-weight: normal; /* 去掉默认加粗 */
  font-size: inherit; /* 继承字号，按需自定义 */
}

/* 9. 清除浮动（可选，解决父元素高度塌陷） */
.clearfix::after {
  content: "";
  display: block;
  clear: both;
  height: 0;
  visibility: hidden;
}
.clearfix {
  zoom: 1; /* 兼容 IE6/7 */
}
```

# Elment-plus
官网:https://element-plus.org/zh-CN/
### 初步导入
1. 安装插件  
pnpm add elment-plus  
pnpm install -D unplugin-vue-components unplugin-auto-import  
pnpm i @element-plus/icons-vue(Element Plus 官方为 Vue 3 专门提供的图标库)
2. 在vite.config.js
```javascript
import { defineConfig } from 'vite'
import AutoImport from 'unplugin-auto-import/vite'
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'

export default defineConfig({
  // ...
  plugins: [
    // ...
    AutoImport({
      resolvers: [ElementPlusResolver()],
    }),
    Components({
      resolvers: [ElementPlusResolver()],
    }),
  ],
})
```

### 导入css样例
```javascript
import 'element-plus/theme-chalk/index.css'
import 'element-plus/theme-chalk/dark/css-vars.css'
```
