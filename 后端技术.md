## JavaMail 邮件工具
### 前置准备
1. 登录 QQ 邮箱 → 设置 → 账户 → 开启 POP3/SMTP 服务
   smtp.qq.com(实测后更建议用qq别的太搞了)
2. Outlook / Hotmail 邮箱（微软官方）
配置参数
SMTP 服务器：smtp.office365.com
端口：587
直接用邮箱登录密码即可（无需授权码）
3. Gmail 邮箱（谷歌邮箱）
配置参数
SMTP 服务器：smtp.gmail.com
端口：587
需要开启「应用专用密码」

### 完整工具类
```java
public class EmailCodeUtil {
    // 邮箱配置（修改为你的QQ邮箱 + 授权码）
    private static final String EMAIL_FROM = "你的QQ邮箱@qq.com";
    private static final String EMAIL_AUTH_CODE = "你的邮箱授权码";
    private static final String SMTP_HOST = "smtp.qq.com";

    /**
     * 生成6位随机数字验证码
     */
    public static String generateCode() {
        return String.format("%06d", new Random().nextInt(999999));
    }

    /**
     * 发送验证码到指定邮箱
     * @param toEmail 接收方邮箱
     * @param code 验证码
     * @return 发送结果
     */
    public static boolean sendEmailCode(String toEmail, String code) {
        // 1. 配置SMTP服务器参数
        Properties props = new Properties();
        props.setProperty("mail.smtp.host", SMTP_HOST);
        props.setProperty("mail.smtp.port", "587");
        props.setProperty("mail.smtp.auth", "true");
        props.setProperty("mail.smtp.starttls.enable", "true");

        // 2. 创建邮箱会话（登录邮箱）
        Session session = Session.getInstance(props, new Authenticator() {
            @Override
            protected PasswordAuthentication getPasswordAuthentication() {
                return new PasswordAuthentication(EMAIL_FROM, EMAIL_AUTH_CODE);
            }
        });

        try {
            // 3. 构建邮件内容
            Message message = new MimeMessage(session);
            message.setFrom(new InternetAddress(EMAIL_FROM)); // 发件人
            message.setRecipient(Message.RecipientType.TO, new InternetAddress(toEmail)); // 收件人
            message.setSubject("【身份验证】您的验证码"); // 邮件标题
            message.setText("您的验证码是：" + code + "，5分钟内有效，请勿泄露给他人！"); // 邮件内容

            // 4. 发送邮件
            Transport.send(message);
            System.out.println("验证码发送成功！验证码：" + code);
            return true;
        } catch (MessagingException e) {
            e.printStackTrace();
            return false;
        }
    }

    // 测试主方法
    public static void main(String[] args) {
        // 生成验证码
        String code = generateCode();
        // 发送到目标邮箱
        sendEmailCode("接收方邮箱@xxx.com", code);
    }
}
```
## lombok在使用之初失效
根源:IDEA没有正确识别注解处理器
解决方法一:
IDEA右边侧边栏>maven>生命周期>clean>compile  
搞好后字节码文件(.class)会有get和set 但还有可能出现没有彻底解决的情况
解决方法二:
```xml
<annotationProcessorPaths>
    <path>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <!--这一步是重点-->
        <version>${lombok.version}</version>
        <!--这一步是重点-->
    </path>
</annotationProcessorPaths>
```
这样搞完之后应该就没事了

## 代理对象
### 是什么
你是全栈小阿巴 你建了一个这样的类
```
//很伪的代码
ServiceImpl{
    @Transactional
    public void a{
        //业务a
    }

    public void b{
        //业务b
    }
}
```
恭喜你成功建了一个**原生对象**  
你在另一个类@Autowired Impl类的时候 实际上注入了**代理对象**  

代理对象是对原生对象的加强 比如事务出错后rollback 都是代理对象做的事情

代理有两种:  
**静态代理**(提前写死 不太好用)  
**动态代理**(运行时 代码自动生成 好 aop 事务 都是这个)

### 坑
#### 问题: 事务失效?
你原生对象中的b方法想要调用a方法  

这有啥难的 于是你这样写:
```
    public void b{
        a()
        //业务b
    }
```
但是后续debug的时候 你会发现**事务失效**了!  
这是因为实际上你写的代码并不是你写的代码!  

你可能会一脸疑惑 没关系 我来告诉你你实际写了什么:
```
    public void b{
        this.a()
        //业务b
    }
```
这个this.a是什么?  
是**原生对象**中的a方法  
原生对象是没有事务的功能的!

要想使用本类的 带有@Transactional的方法 且希望事务生效  
**必须使用代理对象**
#### 解决办法
1. 自己注入自己的**代理对象**
```
ServiceImpl{
    @Autowired
    private ServiceImpl serviceImpl

    @Transactional
    public void a{
        //业务a
    }

    public void b{
        serviceImpl.a()//这里是重点重点重点重点重点!
        //业务b
    }
}
```
2. 用spring提供的方法拿到代理对象
```
ServiceImpl{

    @Transactional
    public void a{
        //业务a
    }

    public void b{
        //这里是重点重点重点重点重点!
        Service proxy = (Service) AopContwxt.currentProxy();
        proxy.a()
        //业务b
    }
}
```
这个方法需要导入依赖 还要改启动类注解/接口 麻烦 算了 不管了

## 线程池
在一五馄饨里出现的场景:selecter要调用多个finance模块有关的service 来查询方法  
原(伪)代码如下:
```java
@Autowired
private List<FinanceProvider> providers;

public Map<财务信息> getFinanceMap(){
     Map<财务信息> result
    for(FinanceProvider provider:providers){
        财务信息 temp =  provider.selectMap();
        Map.put(财务信息);
    }
    return result;
}
```
这样写for是串行的 如果查两次 一次80ms 一次60ms 最后这个接口要消耗140ms    
这不好 因为两次查询没有依赖关系 明明可以并行(同时执行) 没必要串行  
这就需要**线程池**介入
### 使用
1. 注入线程池:
```java
    private final Executor financeExecutor;  // 用 Spring 的线程池，不要自己 new Thread
    public FinanceDataServiceImpl(@Qualifier("generalExecutor") Executor financeExecutor) {
        this.financeExecutor = financeExecutor;
        }
```
@Qualifier("generalExecutor"):指定线程池为generalExecutor(通用线程池)

2. 使用  
注意:新开的线程不能用原有的BaseContent(ThreadLocal)
```java
public Result<List<FinanceVo>> getSingleFinanceData() {
        Long userId = BaseContext.getCurrentId();
        List<CompletableFuture<Map<LocalDate, Integer>>> futures = new ArrayList<>();
        //1.执行异步
        for (FinanceProvider provider : providers){
            //异步任务<任务返回值类型>
            CompletableFuture<Map<LocalDate, Integer>> future =
                    //开启异步任务
                    CompletableFuture.supplyAsync(()->{
                        try{
                            BaseContext.setCurrentId(userId);//给子线程设置当前用户 ID
                            return provider.getFinanceSimpleData();
                        } finally {
                            BaseContext.clearAll();//清理线程局部变量，防止内存泄漏、数据错乱
                        }
                    },financeExecutor);// 指定线程池
            futures.add(future);
        }
        //2.等待异步
        CompletableFuture<?>[] arr = futures.toArray(new CompletableFuture[0]);//传参:空数组模版
        CompletableFuture.allOf(arr).join();
        // .allOf(数组)
        // 作用：等待【数组中所有的异步任务】全部执行完成
        // .join()
        // 作用：让主线程【阻塞在这里】，不继续往下走 直到：所有子线程（查food、payment、travel...）全部查完，才放行

        // 3.处理结果(略)
    }
```
3. 配置
```java
package com.createpen.fifteenhundun.common.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.scheduling.annotation.EnableAsync;
import org.springframework.scheduling.concurrent.ThreadPoolTaskExecutor;

import java.util.concurrent.Executor;
import java.util.concurrent.ThreadPoolExecutor;

@Configuration
@EnableAsync
public class AsyncConfig {

    /**
     * 邮件通知专用线程池
     */
    @Bean("emailExecutor")
    public Executor emailExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        // 核心线程数：常驻线程数量
        executor.setCorePoolSize(2);
        // 最大线程数：高峰期最多创建的线程数
        executor.setMaxPoolSize(5);
        // 队列容量：核心线程满后，任务进入队列等待
        executor.setQueueCapacity(100);
        // 线程空闲时间：超过核心线程数的线程，空闲多久后销毁（秒）
        executor.setKeepAliveSeconds(60);
        // 线程名前缀：方便日志排查
        executor.setThreadNamePrefix("email-notify-");
        // 拒绝策略：队列满且达到最大线程数时的处理方式
        // CallerRunsPolicy：由调用线程（主线程）执行，起到降级作用
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
        // 等待所有任务结束后再关闭线程池
        executor.setWaitForTasksToCompleteOnShutdown(true);
        // 等待时间（秒）
        executor.setAwaitTerminationSeconds(60);
        executor.initialize();
        return executor;
    }

    /**
     * 通用异步任务线程池
     */
    @Bean("generalExecutor")
    public Executor generalExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(5);
        executor.setMaxPoolSize(10);
        executor.setQueueCapacity(200);
        executor.setThreadNamePrefix("async-task-");
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.AbortPolicy());
        executor.initialize();
        return executor;
    }
}
```
