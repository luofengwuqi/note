## JavaMail 邮件工具
### 前置准备
1. 登录 QQ 邮箱 → 设置 → 账户 → 开启 POP3/SMTP 服务
   smtp.qq.com(实测后更建议用qq别的太搞了)
2. Outlook / Hotmail 邮箱（微软官方）
配置参数
SMTP 服务器：smtp.office365.com
端口：587
直接用邮箱登录密码即可（无需授权码）
3. Gmail 邮箱（谷歌邮箱）
配置参数
SMTP 服务器：smtp.gmail.com
端口：587
需要开启「应用专用密码」

### maven依赖
```maven
<dependencies>
    <!-- JavaMail 邮件发送核心依赖 -->
    <dependency>
        <groupId>com.sun.mail</groupId>
        <artifactId>javax.mail</artifactId>
        <version>1.6.2</version>
    </dependency>
</dependencies>
```
### 完整工具类
```java
public class EmailCodeUtil {
    // 邮箱配置（修改为你的QQ邮箱 + 授权码）
    private static final String EMAIL_FROM = "你的QQ邮箱@qq.com";
    private static final String EMAIL_AUTH_CODE = "你的邮箱授权码";
    private static final String SMTP_HOST = "smtp.qq.com";

    /**
     * 生成6位随机数字验证码
     */
    public static String generateCode() {
        return String.format("%06d", new Random().nextInt(999999));
    }

    /**
     * 发送验证码到指定邮箱
     * @param toEmail 接收方邮箱
     * @param code 验证码
     * @return 发送结果
     */
    public static boolean sendEmailCode(String toEmail, String code) {
        // 1. 配置SMTP服务器参数
        Properties props = new Properties();
        props.setProperty("mail.smtp.host", SMTP_HOST);
        props.setProperty("mail.smtp.port", "587");
        props.setProperty("mail.smtp.auth", "true");
        props.setProperty("mail.smtp.starttls.enable", "true");

        // 2. 创建邮箱会话（登录邮箱）
        Session session = Session.getInstance(props, new Authenticator() {
            @Override
            protected PasswordAuthentication getPasswordAuthentication() {
                return new PasswordAuthentication(EMAIL_FROM, EMAIL_AUTH_CODE);
            }
        });

        try {
            // 3. 构建邮件内容
            Message message = new MimeMessage(session);
            message.setFrom(new InternetAddress(EMAIL_FROM)); // 发件人
            message.setRecipient(Message.RecipientType.TO, new InternetAddress(toEmail)); // 收件人
            message.setSubject("【身份验证】您的验证码"); // 邮件标题
            message.setText("您的验证码是：" + code + "，5分钟内有效，请勿泄露给他人！"); // 邮件内容

            // 4. 发送邮件
            Transport.send(message);
            System.out.println("验证码发送成功！验证码：" + code);
            return true;
        } catch (MessagingException e) {
            e.printStackTrace();
            return false;
        }
    }

    // 测试主方法
    public static void main(String[] args) {
        // 生成验证码
        String code = generateCode();
        // 发送到目标邮箱
        sendEmailCode("接收方邮箱@xxx.com", code);
    }
}
```
## lombok在使用之初失效
根源:IDEA没有正确识别注解处理器
解决方法一:
IDEA右边侧边栏>maven>生命周期>clean>compile  
搞好后字节码文件(.class)会有get和set 但还有可能出现没有彻底解决的情况
解决方法二:
```xml
<annotationProcessorPaths>
    <path>
        <groupId>org.projectlombok</groupId>
        <artifactId>lombok</artifactId>
        <!--这一步是重点-->
        <version>${lombok.version}</version>
        <!--这一步是重点-->
    </path>
</annotationProcessorPaths>
```
这样搞完之后应该就没事了
