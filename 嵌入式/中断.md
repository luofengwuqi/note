# 外部中断(EXTI)

## 信号路径
```
GPIO(引脚电平变化) → AFIO(选中断线) → EXTI(边沿检测) → NVIC(优先级仲裁) → CPU(执行中断函数)
GPIO → AFIO → EXTI → 其他外设(事件,不经过CPU)
```
- **NVIC** 帮 CPU 处理中断优先级,不产生中断,只决定"谁先跑"
- 类比:EXTI 是叫号系统,CPU 是医生,NVIC 是分诊台
- **同一编号的 Pin 不能同时触发中断**(PA0 和 PB0 抢的是 EXTI_Line0,只能选一个)

## 三个文件
| 文件 | 作用 |
|---|---|
| `CountSensor.c` | 初始化 GPIO/EXTI/NVIC + 中断服务函数 + 计数变量 |
| `CountSensor.h` | 对外只暴露 `CountSensor_Init()` 和 `getCount_()` |
| `user/main.c` | 调初始化、OLED 显示计数 |

这种"驱动单独成模块"的写法,是把外设细节从 `main.c` 里抽出来。`main.c` 只关心"拿计数去显示",不关心中断怎么配的。

## CountSensor.c 初始化五步
1. **开时钟**:`GPIOA` + `AFIO`(EXTI/NVIC 时钟默认自动开启,不用管)
2. **配引脚**:PA0 → `GPIO_Mode_IPU` 上拉输入(按键一端接 GND,松开为高,按下为低)
3. **AFIO 选线**:`GPIO_EXTILineConfig(GPIO_PortSourceGPIOA, GPIO_PinSource0)` —— 把 PA0 接到 EXTI_Line0
4. **配 EXTI**:`EXTI_Line0` + `EXTI_Mode_Interrupt`(中断模式,不是事件模式) + `EXTI_Trigger_Falling`(下降沿)
5. **配 NVIC**:优先级分组 2(2 位抢占 + 2 位子优先级),抢占 1、子 1

```c
void CountSensor_Init(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);   //1. GPIOA 时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO,  ENABLE);   //   AFIO 时钟

	GPIO_InitTypeDef obj = { 0 };                            //2. 引脚
	obj.GPIO_Pin   = GPIO_Pin_0;
	obj.GPIO_Mode  = GPIO_Mode_IPU;       // 上拉输入
	obj.GPIO_Speed = GPIO_Speed_2MHz;     // 输入模式下速度无实际意义
	GPIO_Init(GPIOA, &obj);

	GPIO_EXTILineConfig(GPIO_PortSourceGPIOA, GPIO_PinSource0);  //3. 选线

	EXTI_InitTypeDef extiObj;                                //4. EXTI
	extiObj.EXTI_Line    = EXTI_Line0;
	extiObj.EXTI_LineCmd = ENABLE;
	extiObj.EXTI_Mode    = EXTI_Mode_Interrupt;
	extiObj.EXTI_Trigger = EXTI_Trigger_Falling;             // 下降沿
	EXTI_Init(&extiObj);

	NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);          //5. NVIC
	NVIC_InitTypeDef nvicObj;
	nvicObj.NVIC_IRQChannel                   = EXTI0_IRQn;
	nvicObj.NVIC_IRQChannelCmd                = ENABLE;
	nvicObj.NVIC_IRQChannelPreemptionPriority = 1;
	nvicObj.NVIC_IRQChannelSubPriority        = 1;
	NVIC_Init(&nvicObj);
}
```

> 上拉输入 + 下降沿的组合是按键计数的标准做法:按下瞬间电平 1→0 触发一次,松手是 0→1(上升沿)不触发,所以**一次按下只加一**。

## 中断服务函数
```c
void EXTI0_IRQHandler(void)
{
	if (EXTI_GetITStatus(EXTI_Line0) == SET)   // 1. 确认是本线触发
	{
		Delay(20);                              // 2. 等抖动过去
		if (GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_0) == 0)  // 3. 复查电平
			Count_++;                           //    真按下才计数
		EXTI_ClearITPendingBit(EXTI_Line0);      // 4. 清标志(必须)
	}
}
```

逻辑是三步:**验身份 → 消抖 → 清标志**。

- 按键机械抖动会有多个下降沿,所以延时 20ms 再读一次引脚:如果还是低电平,说明是真的按住了;如果是高电平,刚才那个是毛刺。
- 函数名必须是 `EXTI0_IRQHandler`,这是 `startup_stm32f10x_md.s` 里写死的向量表名字,拼错就永远不会被调用,而且**不报错**。
- `EXTI_ClearITPendingBit` 不清的话,退出中断后标志位还挂着,CPU 会立刻再进一次,看起来像死循环卡死。

## 数据共享
```c
uint16_t Count_;                  // 中断里 ++,主循环里读
uint16_t getCount_(void){ return Count_; }
```
用全局变量 + 一个 getter 把计数传出去。注意两点:
- 中断和主循环共享的变量,规范上要加 `volatile`(`volatile uint16_t Count_;`),否则编译器的优化可能把它缓存进寄存器,导致主循环读到旧值。
- `uint16_t` 是 16 位,而 STM32 是 32 位总线,读写本身是单条指令、不会被打断,所以这里读的时候不用担心"读到一半被中断改了"的撕裂问题。

## main.c
```c
#include "stm32f10x.h"
#include "OLED.h"
#include "../CountSensor.h"

int main(void)
{
	CountSensor_Init();              // 外部中断初始化已挪到 CountSensor.c
	OLED_Init();
	OLED_ShowString(1, 1, "Count:");
	while (1)
	{
		OLED_ShowNum(1, 7, getCount_(), 5);   // 变化的值放循环里刷
	}
}
```

- 固定文字 "Count:" 放循环外,只刷数字,避免无谓的重复写屏
- `OLED_ShowNum` 定长 5 位、右对齐补零,位数不变,不会留残影
- 头文件用 `"../CountSensor.h"` 相对路径,因为 `main.c` 在 `user/` 子目录里

`main.c` 里还躺着 `bilnk()` / `shout()` / `init_GPIO()` / `OLED()` 四个旧实验的函数(引脚闪烁、PB12 翻转、GPIO 初始化),现在都没被调用了,是上一版按钮控灯实验的遗留物。留着不影响编译,但会让人误以为还在用,建议删掉或注释掉。

## 坑清单
| 现象 | 原因 |
|---|---|
| 中断函数永远不执行 | 函数名拼错(必须是 `EXTI0_IRQHandler`)、`NVIC_IRQChannelCmd` 没使能、`EXTI_LineCmd` 没 ENABLE |
| 进了中断就出不来 / 疯狂重复进 | 没调 `EXTI_ClearITPendingBit` |
| 按一下加好多次 | 没消抖,或消抖后没复查引脚电平 |
| PA0 触发不了、PB0 却有用 | 忘开 AFIO 时钟,或 `GPIO_EXTILineConfig` 的端口/引脚号写错 |
| 计数不涨 / 一直显示旧值 | 变量没加 `volatile`,被编译器优化掉 |
| 编译报 `uint16_t` 未定义 | `CountSensor.h` 里没 `#include "stm32f10x.h"`,靠包含顺序侥幸通过(现在是 `main.c` 先包了标准头)。驱动头文件应自己包含所需头 |

## 可以改进的地方
当前在中断里 `Delay(20)` 是**阻塞式消抖**,这 20ms 里 CPU 什么都干不了,OLED 刷新会被明显卡顿,而且中断里不宜做长延时。

更好的两种做法:
1. **定时器扫描**:10ms 定时中断里采样引脚,连续两次为低才认按下(状态机消抖)
2. **中断只置标志**:`EXTI0` 里只 `KeyFlag = 1;` 并清标志,消抖和计数放到主循环里做

另外计数到 65535 会溢出回 0,如果要长期统计用 `uint32_t`。
