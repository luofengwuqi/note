# 串口
Tx:Transmit数据发送引脚  
Rx:Receive数据接收引脚  
## 串口数据帧格式
![](./assets/2026102803.png)
常态(空闲):高电压1  
开始传数据:低电压0  
起始位后面跟着的8位是有效数据(D0-D7)  
停止:高电压1

**注意:** 要倒过来发 比如想发一个27(00011011)
那么D0 = 1 D1=1 D2=0 D3=1 D4=1 D5=0 D6=0 D7=0

常用的两种:
八位不带校验位 & 九位带校验位  
接收方提要求 奇校验还是偶校验(奇数个1/偶数个1) 发送方根据实际情况填写校验位 最终发过来看是否符合要求

## USART 
![](./assets/2026102804.png)
```C
/**
 * @brief  串口初始化函数
 * @param  USARTx: 串口外设基地址指针，可选 USART1 / USART2 / USART3 等
 * @param  USART_InitStruct: 串口初始化结构体指针，包含串口各项配置参数
 * @retval 无
 * @note   该函数按照传入结构体里的参数，配置串口波特率、数据位、停止位、校验、收发模式
 */
void USART_Init(USARTTypeDef *USARTx,
                USART_InitTypeDef *USART_InitStruct);  // 初始化的参数


/**
 * @brief  串口初始化结构体，用来统一存放串口配置信息
 */
struct USART_InitTypeDef
{
    uint32_t USART_BaudRate;        // 波特率：串口通信速率，常见 9600、115200
    uint16_t USART_WordLength;      // 数据位长度
                                    // - USART_WordLength_8b：8位数据位（最常用）
                                    // - USART_WordLength_9b：9位数据位
    uint16_t USART_StopBits;        // 停止位长度，标识一帧数据结束
                                    // - USART_StopBits_0_5：0.5位停止位
                                    // - USART_StopBits_1：  1位停止位（最常用）
                                    // - USART_StopBits_1_5：1.5位停止位
                                    // - USART_StopBits_2：  2位停止位
    uint16_t USART_Parity;          // 奇偶校验方式，用于简单检错
                                    // - USART_Parity_No：   无校验（最常用）
                                    // - USART_Parity_Even： 偶校验
                                    // - USART_Parity_Odd：  奇校验
    uint16_t USART_Mode;            // 串口数据收发方向，可按位或同时开启
                                    // - USART_Mode_Tx：仅发送
                                    // - USART_Mode_Rx：仅接收
                                    // - USART_Mode_Tx | USART_Mode_Rx：同时开启发送+接收
};
```
具体配置如下
```C
int main(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE);

    USART_InitTypeDef USART_InitStruct;

    USART_InitStruct.USART_BaudRate = 115200;
    USART_InitStruct.USART_Mode = USART_Mode_Tx | USART_Mode_Rx;
    USART_InitStruct.USART_WordLength = USART_WordLength_8b;
    USART_InitStruct.USART_StopBits = USART_StopBits_1;
    USART_InitStruct.USART_Parity = USART_Parity_No;

    USART_Init(USART1, &USART_InitStruct);

    while(1)
    {

    }
}
```
