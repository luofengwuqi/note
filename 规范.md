# git规范
## git提交信息规范
| 类型       | 含义                                                                 |
|------------|----------------------------------------------------------------------|
| `feat`     | 新增功能（feature）                                                  |
| `fix`      | 修复 bug                                                             |
| `docs`     | 仅修改文档（README、注释等）                                         |
| `style`    | 仅修改样式（不影响代码逻辑）                                         |
| `refactor` | 重构代码（既不新增功能，也不修复 bug）                               |
| `test`     | 添加/修改测试代码（新手可选）                                       |
| `chore`    | 构建/工具类改动（不影响业务代码）                                     |
