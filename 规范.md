# git规范
## git提交信息规范
| 类型       | 含义                                                                 |
|------------|----------------------------------------------------------------------|
| `feat`     | 新增功能（feature）                                                  |
| `fix`      | 修复 bug                                                             |
| `docs`     | 仅修改文档（README、注释等）                                         |
| `style`    | 仅修改样式（不影响代码逻辑）                                         |
| `refactor` | 重构代码（既不新增功能，也不修复 bug）                               |
| `test`     | 添加/修改测试代码（新手可选）                                       |
| `chore`    | 构建/工具类改动（不影响业务代码）                                     |

# 前端
## ESLint启用自动规范
![](./assets/2026-2-19-1.png)
```json
//在原有的后面添加
{
    //保存时eslint自动修复
    "editor.codeActionsOnSave": {
        "source.fixAll.eslint": "always"
    },
    //保存代码不自动格式化
    "editor.formatOnSave": false
}
```
## 全局关闭组件名多单词
在项目根目录的 .eslintrc.js（或 .eslintrc）文件中，添加规则配置：
```javascript
module.exports = {
  // ...其他配置
  rules: {
    // 关闭组件名必须是多单词的校验
    'vue/multi-word-component-names': 'off'
  }
}
```
